# Woodlands Group Website

Company facade for **Woodlands Transport Group** with scroll-scrub video frames and business hierarchy markers.

## Run

```bash
cd web
npm install
npm run dev
```

Open http://localhost:3000

## Structure

- Hero — group intro
- Journey — scroll-linked video frames + node markers (0–7)
- Businesses — service cards for each unit
- About / Contact

## Assets

- Frames: `public/scroll-frames/` (182 JPEGs)
- Logos: `public/brands/`
- Data: `src/data/businesses.ts`
